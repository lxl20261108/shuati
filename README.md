# 考研刷题（338 生物化学 / 821 食品工艺学）

纯前端的个人刷题工具。没有后端，也不用登录。答题记录、错题、收藏和进度只存在本机浏览器的 localStorage 里，不会上传到任何服务器。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面、样式和全部交互逻辑 |
| `questions.js` | 题库（`window.QUESTIONS = [...]`），共 2266 题 |
| `manifest.webmanifest` | “添加到主屏幕”配置 |
| `sw.js` | 离线缓存 |
| `icon.svg`、`icon-180.png`、`icon-512.png` | 应用图标 |
| `题库转换报告.md` | 题目统计、重复题、缺失答案、需人工确认清单 |
| `tools/x2t.js`、`tools/convert.js` | 从 docx 重新生成题库的脚本（可选） |

## 本地打开

- 最简单的方式：双击 `index.html`。题库通过 `<script>` 加载，所以 file:// 下也能用。这种方式下离线缓存（Service Worker）不会启用，其余功能正常。
- 要测试离线缓存，就在本目录启动一个本地服务器：
  ```
  npx serve .
  ```
  或者 `python -m http.server 8000`，然后打开显示的地址。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库，例如 `quiz`。题库是个人资料，建议设成 Private。注意：免费账号的 Private 仓库不能开 Pages，只能用 Public 仓库或改用 Vercel。
2. 把本目录下的所有文件上传到仓库根目录（网页上点 “Add file → Upload files” 拖进去即可）。
3. 打开仓库 Settings → Pages → Source 选 “Deploy from a branch”，Branch 选 `main`、目录选 `/ (root)`，然后保存。
4. 等 1～2 分钟，访问 `https://你的用户名.github.io/quiz/`。

## 部署到 Vercel

1. 登录 https://vercel.com（可以用 GitHub 账号）。
2. 方式 A：把上面的 GitHub 仓库 Import 进来，Framework Preset 选 “Other”，构建命令留空，点 Deploy。Vercel 支持私有仓库。
   方式 B：本机运行 `npx vercel`，在本目录按提示一路回车。
3. 部署完成后会得到 `https://xxx.vercel.app` 地址。

## 手机添加到主屏幕

- **iPhone（Safari）**：用 Safari 打开网址 → 点底部“分享”按钮 → “添加到主屏幕” → 添加。
- **安卓（Chrome / Edge）**：打开网址 → 右上角菜单 ⋮ → “添加到主屏幕”或“安装应用”。
- **安卓国产浏览器**：一般在菜单里的“添加到桌面”。部分浏览器不支持离线，建议用 Chrome 或 Edge。

首次打开时要联网，打开一次后题库就缓存到手机，之后断网也能用。

## 使用说明

- 首页先选科目、筛选（全部/真题/补充题/错题/收藏/未做）和模式（顺序/随机/只刷错题/只刷收藏），再点“开始刷题”或点某一章。
- 单选、判断：点选项后点“提交”。多选：选全部选项后提交，必须与答案完全一致才算对。题库目前没有多选题，功能已就绪。
- 填空：每个空一个输入框。是否忽略首尾空格、全半角、大小写，可以在“设置”里改。原答案无法逐空拆分的填空题，提交后显示原答案，由你自评。
- 简答、名词解释、论述等：点“看答案”后自评“我会/不会”。点“不会”计入错题本。
- 答错会自动加入错题本。设置里可以开关“连续答对 2 次自动移出”。答题页也能手动移出。
- 右上角 ☆ 收藏，▦ 打开答题卡（绿=对，红=错，黄=跳过），点题号可以跳转。
- 首页每章右侧的“重置”用来清除本章进度和错题（收藏保留）。“设置 → 重置全部数据”清除所有记录。两项操作都要二次确认。
- 换手机或清理浏览器数据会丢失记录。

## 更新题库

1. 修改 docx 后，解压 docx（它本质上是 zip 文件），在解压目录的上一级运行 `node tools/x2t.js <解压目录名>`，得到 txt 文件。
2. 在同一目录运行 `node tools/convert.js <输出目录>`，生成新的 `questions.js` 和报告。
3. 把 `sw.js` 第一行的 `VERSION` 改成新值（如 `kyquiz-v2`），再重新部署。手机上打开两次即可拿到新题库。

注意：答题记录按题目 ID 保存，ID 不变记录就不会丢。
